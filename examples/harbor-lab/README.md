# Harbor Lab example

A fake community workshop. Used only to prove the kit works.

Canonical homes:

- tool condition facts → `concepts.csv` only when they are reusable ideas; otherwise stay in `sources.csv` until they earn a concept
- workshop invariants → `rules.csv`
- incoming notes → `sources.csv`
- where a note went → `intake_log.csv`
- what file to open → `router.md` plus `file_index.csv`

Nothing here is a real person, shop, or private record.
